### Bug report
Title: Transparent line at edge of image when a border image effect is added

I don't believe this issue was present in version 17.1.0. If it was, I never noticed it despite taking dozens of screenshots per day.

When adding an image effect border of any size and color with type "outside", a single pixel width line is added on the left and top edges of the image **_inside_** the border. If the image is saved as .PNG file type, the line is transparent. The line is not visible if border type "inside" is used, likely because it's covered up by the border. Hopefully the images uploaded to GitHub show the issue after being compressed...
