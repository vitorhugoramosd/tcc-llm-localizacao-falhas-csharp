# Conferência das issues sorteadas

As issues foram conferidas no GitHub na ordem do sorteio (`ordem_sorteio.json`, semente 20261107) até completar três defeitos por repositório. Os critérios são os da seção 3.2.1 do TCC:

* **a)** a issue relata um comportamento incorreto, e não um pedido de funcionalidade ou uma refatoração. No piloto, isso foi conferido pelo rótulo que a própria equipe do projeto deu à issue;
* **b)** a issue tem descrição em texto além do título.

Os critérios c) e d) (commit de correção ligado à issue e alteração de pelo menos um arquivo .cs que não seja de teste) já foram aplicados antes do sorteio, pelo `02_filtrar.py`.
